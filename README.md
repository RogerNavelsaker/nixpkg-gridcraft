# nixpkg-gridcraft

Nix package for [ArtCraft Gridcraft](https://github.com/storytold/gridcraft), using its official Linux x86_64 release archive. The package installs the app directly; it does not include the ArtCraft launcher or provide an auto-updater.

Pinned upstream release: `v0.11.1`.

```sh
nix build
nix run
```
